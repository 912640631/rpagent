# AI-RP 快照保存配套状态，故事记录独立于模型上下文

React 前端需要中途存读档与完整故事记录，而现有模型上下文会压缩，应用状态与规则状态也分别持久化。设计选择在系统等待玩家输入的安全节点串行捕获配套 Agent 上下文、规则状态、随机数状态和玩家可见记录，并将故事记录独立于模型上下文保存；相较于复制单个规则文件或重放对话，增加了快照协调与历史存储，但能恢复一致的 AI-RP 现场，避免读档后 Agent 仍记得未来行动、压缩删除界面历史或重放导致重复执行。读档保留当前模型与风格指令，方便对同一局面做模型对照测试。

访谈已确认上述行为；整体设计与原有实现修改范围仍待最终确认。
