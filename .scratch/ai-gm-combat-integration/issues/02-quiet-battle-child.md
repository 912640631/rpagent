# 02: 安静的战斗子会话

**What to build:** 主 GM 只发起一场目录怪物战斗，玩家在 dsh Web 或 Desktop 的持续运行子会话里直接操作杰洛特。战斗子 agent 结算怪物行动并叙事，结束后交回可核对的结果；普通战斗回合不打断主 GM。

**Blocked by:** 01 — 统一判定与共享资源。

**Status:** ready-for-agent

- [ ] 主 GM 能提交场景、已有剧情事实、参战者、目标和资源状态，获得可供玩家打开的持续运行战斗子会话。
- [ ] 玩家直接在子会话中选择杰洛特行动；怪物行动由子 agent 推进，直到再次需要玩家决定或战斗结束。
- [ ] 子会话的普通结算通知可逐个启用或禁用；未选择安静模式的既有子会话保持原有通知行为。
- [ ] 安静模式在子会话冷恢复后仍生效；普通回合不唤醒主 GM，终局、重大事件和运行错误仍能上报，且不会因模型回报提示重复发送。
- [ ] 战斗结束向主 GM 发送能与战斗最终状态核对的结构化结算，以及简短叙事摘要；主 GM 可据此继续剧情，无需读取所有战斗回合。
- [ ] 有覆盖普通与安静模式、玩家直达子会话、一次完整目录怪战斗及战后返回的外部行为测试。
