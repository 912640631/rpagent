# 03: 自创敌人与自由战术

**What to build:** 主 GM 可以在即兴剧情中创造单只敌人并判断其强弱；战斗子 agent 将该意图转为合法且开战后固定的战斗数据。玩家可以提出固定招式表以外的临场战术，由引擎结算结果。

**Blocked by:** 02 — 安静的战斗子会话。

**Status:** ready-for-agent

- [ ] 主 GM 无需填写完整数值，只提交敌人的叙事描述与强弱意图；子 agent 在首回合前生成并校验战斗数据。
- [ ] 自创敌人的属性、招式和相关配置随战斗保存；开战后不能为迎合剧情暗改，不引入固定强度等级表。
- [ ] 玩家能用自然语言提出利用环境、配合、佯攻等战术；子 agent 转成可校验的目标、消耗、难度与效果后才由引擎结算。
- [ ] 不合法或无法表达的战术不会改变战斗状态，玩家能获得可理解的调整提示。
- [ ] 自创敌人战斗与目录怪战斗都能完整结束、交回结构化结果，并有覆盖生成、锁定和自由战术的行为测试。
