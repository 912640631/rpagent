# 01: 统一判定与共享资源

**What to build:** 玩家在同一局中完成叙事判定、杰洛特对单只目录怪物的战斗，再回到叙事时，希望与绝望始终由同一个持久化账本结算。战斗保留原有战斗效果，同时采用已确认的杰洛特二元骰与资源规则。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 新局从希望 2、绝望 0 开始；继续同一局不会自动重置，资源上限分别为 6 和 12。
- [x] 杰洛特战斗判定使用希望和绝望各一颗 d12；同点暴击自动成功，希望面较高或暴击获得 1 希望，绝望面较高获得 1 绝望，成功与失败均按此结算。
- [x] 玩家可在战斗判定前花 2 希望获得 +3；该加成可与环境优势或劣势并用，余额不足时行动不结算。
- [x] 怪物招式与强化从共享绝望池扣费；战斗期间不再另行调用 NarrativeDice 掷第二次判定。
- [x] 通过对外会话接口运行“叙事判定→单怪战斗→叙事判定”后，玩家看到的资源值、历史与战斗结果一致，跨进程继续也一致。
- [x] 过期或重复提交不能重复获得或扣除资源；既有单怪战斗能力保持可用，并有可复现的行为测试。
