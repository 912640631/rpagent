# 04: 多对多战斗

**What to build:** 玩家只操作杰洛特，队友和多名敌人由战斗子 agent 自主行动。所有行动、伤势、状态和结局都能准确指向具体参战者，支持类似杰洛特与叶奈法对抗水鬼群的遭遇。

**Blocked by:** 02 — 安静的战斗子会话。

**Status:** ready-for-agent

- [ ] 战斗可包含具有稳定身份、阵营和目标的多名参战者；玩家能明确选择攻击或援助目标。
- [ ] 队友与敌人以各自属性和 d20 判定；队友不使用二元骰，也不产生或消费希望与绝望；敌方仍可按规则消费 GM 绝望。
- [ ] 玩家只在杰洛特可行动或需作出关键抉择时输入；队友与敌人的连续行动由子 agent 推进并给出紧凑、清楚的战况叙述。
- [ ] 范围效果、伤害、状态、失能和死亡按实际参战者结算；一名敌人倒下不自动结束仍有威胁的战斗。
- [ ] 可完整运行杰洛特与叶奈法面对约七只水鬼的可复现遭遇；现有单怪玩法与已完成的战斗交接仍可用。
