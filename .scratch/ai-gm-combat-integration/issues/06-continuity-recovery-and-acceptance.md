# 06: 延续恢复与完整游玩验收

**What to build:** 同一局的剧情与战斗状态能跨支线和中断延续，重复消息不会重复结算。完整玩家路径可从即兴叙事进入不同类型的战斗，再根据真实结果返回主 GM 叙事。

**Blocked by:** 03 — 自创敌人与自由战术；05 — 战斗目标与重大剧情事件。

**Status:** ready-for-agent

- [ ] 同一局进入下一支线时保留已确立的伤势、装备、关系、希望、绝望与战斗后果；只有明确新开一局才重置。
- [ ] dsh 或战斗子会话中断后，玩家能从最后已提交的战斗步骤或待决重大事件恢复；主 GM 恢复在线后可继续处理待决事件。
- [ ] 重复、过期或重发的行动不会重复扣资源、消耗物品、造成伤害或发送相同终局结算。
- [ ] 战后结构化报告能从持久状态重新核对，主 GM 据此续写，不重新掷骰或改写机械结果。
- [ ] 完整验收覆盖目录怪单战、自创敌人战斗，以及杰洛特与叶奈法对多只水鬼的群战；至少一次通过非击杀目标结束。
- [ ] 自动化测试验证可观察规则与契约；完成一次真实 dsh Web 或 Desktop 游玩检查，确认玩家能直达子会话、完成战斗并回到主剧情。
