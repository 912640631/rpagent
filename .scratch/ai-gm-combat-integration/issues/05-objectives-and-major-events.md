# 05: 战斗目标与重大剧情事件

**What to build:** 战斗不再必须以击杀全部敌人结束。玩家可以保护、救援、撤退、劝降或俘获；只有尚未由引擎决定的重大剧情变化需要暂停并交给主 GM。

**Blocked by:** 04 — 多对多战斗。

**Status:** ready-for-agent

- [ ] 主 GM 可在开战时给出保护、救援、撤离、俘获或击退等目标，战斗按目标条件结算并报告结果。
- [ ] 玩家在战斗中改为撤退、劝降或俘获时，子 agent 能通过合法行动更新目标并继续结算。
- [ ] 已在开战场景中确立的风险和增援可按规则出现；新的不可逆 NPC 命运、任务目标变化或主线事实先形成待决事件，暂停战斗交主 GM 决定。
- [ ] 引擎已经结算的伤害、失能和死亡不能被主 GM 推翻；重大机械结果立即上报，由主 GM 决定叙事后果。
- [ ] 主 GM 暂不可达时待决事件保持暂停，玩家能看到清楚状态；普通战术转折仍不唤醒主 GM。
- [ ] 至少一个可复现遭遇通过保护或撤离目标结束，并覆盖重大事件暂停与恢复的外部行为测试。
